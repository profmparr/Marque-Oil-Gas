# Marque Oil & Gas Ltd – Corporate & Project Website

An independent energy website developed to showcase overlooked oil and gas opportunities in mature basins, highlighting the Isle of Man gas development project, environmental commitments, and long-term economic benefits.

## Project Overview
This website serves as a public-facing informational portal for Marque Oil & Gas Ltd. It features multi-tab project breakdowns, interactive development timelines, comparison data regarding local gas versus renewable alternatives, and dedicated resources/FAQ sections. The front-end architecture is built to be lightweight, responsive, and easily maintainable without reliance on heavy frameworks.

## Key Sections & Features
* **The Opportunity:** Overview of the Isle of Man gas discovery, spatial overlap considerations, and resource choices.
* **The Case for Gas:** Strategic advantages covering energy security, price stability, tax revenues, and carbon capture integration.
* **Development Vision:** Step-by-step 5-stage timeline tracking infrastructure progression from Barrow processing to carbon storage.
* **Economic Comparison:** Detailed interactive evaluation criteria comparing local gas development against renewable alternatives.
* **Previous Licences:** A dedicated archive page detailing historical corporate promote licences (e.g., UK 30th Round P2409).
* **Resources & FAQs:** Interactive accordion toggles for common public questions, alongside downloadable document cards cleanly separated into internal Marque files and external industry links.
* **Custom Error Handling:** A fully branded `404.html` page featuring a JavaScript-powered 10-second automatic redirect countdown.

## Tech Stack
* **HTML5 & CSS3:** Manually coded layouts utilizing custom CSS variables, semantic HTML, flexbox, responsive grid systems, and inline SVGs.
* **Vanilla JavaScript:** Event-driven logic for tab switching, interactive image modals, scroll-reveal intersection observers, scroll-to-top functionality, and dynamic copyright year generation.
* **Typography:** Google Fonts (**Sen**) paired with system default fonts (**Segoe UI**) for clean, technical readability.
